# Jimeng Cost Guard

The goal is not to make every clip boring; it is to avoid paying for avoidable retries.

## LOW
- 1–2 visible subjects
- One clear main action
- Natural facial/body movement
- Slow or static camera
- Little or no precise hand-object interaction
- Stable scene and lighting

## MEDIUM
- 2–4 subjects with coordinated reactions
- Two linked actions
- One meaningful object interaction
- Moderate camera move
- Partial occlusion, sitting/standing transitions, turning while moving

Keep only when the action is important to the story.

## HIGH
Simplify before generation when any of these appear:
- Several independent actions happening simultaneously
- Long chains such as walk → grab → turn → fall → catch → speak → run
- Detailed fingers/hands manipulating small objects
- Fast fighting, dancing, acrobatics, complex collisions
- Multiple scene/location changes inside one clip
- Rapid cuts plus aggressive camera motion
- Conflicting camera instructions
- Character or prop state contradicts previous clip

## Simplification order
1. Preserve the story beat.
2. Remove decorative actions.
3. Convert simultaneous actions into sequential reactions.
4. Replace precise hand mechanics with broader body movement when possible.
5. Reduce camera motion before removing essential character action.
6. If still HIGH, split the beat into two clips rather than gambling one expensive generation.
