# Segment Template

Use this exact production order for `split` and `prompt` work.

## Part NN — target 15s

**Story purpose:** One sentence describing why this clip exists.

**Beginning State**
- Character(s): identity, clothing, hairstyle, expression
- Position/posture: where each subject is and what they are doing at frame 1
- Props: relevant held/placed objects
- Environment: location, time, lighting
- Camera: framing/angle if continuity matters

**Action Timeline**
- 0–5s: primary setup/action
- 5–10s: continuation or reaction
- 10–15s: payoff/ending action

The timeline is guidance, not three mandatory cuts. Prefer continuous action when possible.

**Ending State**
- Exact final position/posture
- Relevant expression
- Prop state
- Camera/framing state if needed by next clip

**First-frame image prompt:** Static visual only. Do not describe later motion here.

**Jimeng image-to-video prompt:** Motion, expression change, environmental movement, and camera behavior for this clip only.

**Generation risk:** LOW / MEDIUM / HIGH

**Risk note:** One short line only when MEDIUM/HIGH.
